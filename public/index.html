📡 Stream Physical USB Drive & Hardware Telemetry

Run the Gateway Agent on your physical computer or Raspberry Pi to stream your real USB stick into this cloud portal.
Waiting for Agent

If you have a physical USB drive or local hard drive plugged into your PC/Raspberry Pi and want this Render cloud portal to show its live hardware data in real time, run this command in your project folder:

node gateway-agent.js --cloud https://your-domain.onrender.com --storage E:\
💡 Tip: Replace E:\ with your actual USB drive letter on Windows (e.g. D:\, F:\) or mount path on Linux (e.g. /mnt/usb). The agent will stream telemetry to Render every 15s.

Mount Custom Local Directory

Mount a folder directly on the machine hosting the backend server.

Direct directory mounting is supported when running locally on your hardware. On cloud servers (like Render), use the Gateway Agent above.
